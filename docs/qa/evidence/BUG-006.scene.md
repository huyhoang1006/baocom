📌 TÓM LẠI:
  1. User click "Xuất CSV" trên UI
  2. Frontend gọi GET /api/admin/reports/export
  3. Route handler gọi controller.exportXlsx() (SAI — phải exportCsv)
  4. 💥 Response là XLSX dù URL gợi ý CSV
  5. Downstream tools crash vì expect CSV

💥 ROOT CAUSE: `app/api/admin/reports/export/route.ts:14` gọi `exportXlsx()`
   thay vì `exportCsv()` (đã tồn tại trong controller).
   Hai methods `exportCsv()` (line 65) và `exportXlsx()` (line 116) đều có
   nhưng route `/export` chỉ wire tới XLSX.

🔧 FIX Option A (route ngắn = CSV, route dài = XLSX):
```typescript
// app/api/admin/reports/export/route.ts
import { AdminReportsController } from '@/controllers/AdminReportsController'
const controller = new AdminReportsController()
const auditService = new AuditLogService()

export const GET = withAdmin(async (req, userId) => {
  const { searchParams } = req.nextUrl
  const startDate = searchParams.get('startDate') || ''
  const endDate = searchParams.get('endDate') || ''

  const result = await controller.exportCsv(req)   // ← ĐỔI từ exportXlsx

  await auditService.log({
    action: 'REPORT_EXPORTED',
    entityType: 'report',
    performedBy: userId,
    details: `CSV export for period ${startDate} to ${endDate}`
  })

  return result
})
```
