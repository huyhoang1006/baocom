  async create(data: CreateUserDTO): Promise<CreateUserResult> {
    // ... validate, check duplicate
    const hashedPassword = await hashPassword(data.password)

    const user = await this.userRepository.create({
      ...data,
      password: hashedPassword  // bcrypt hash lưu DB
    })

      user,
      credentials: {
        username: data.username,
        password: data.password  // ← 💥 return CLEARTEXT (chưa hash)

🎬 Scene 8: Frontend hiển thị (1 lần) hoặc bị log lại
─────────────────────────────────────────
  - Browser DevTools Network tab → password hiển thị
  - API gateway/proxy log → password vào log file (production!)
  - Browser extension có thể đọc response → leak thêm
  - Frontend modal thường chỉ show password 1 lần, nhưng response đã ở trong memory

───────────────────────────────────────────────────────────────────────────────

📌 TÓM LẠI:
  1. Admin submit form tạo user với password cleartext
  2. Controller tạo user thành công (hash lưu DB OK)
  3. 💥 Nhưng response trả về cả `credentials.password` = cleartext gốc
  4. Password đã vào: browser memory, devtools log, proxy log, ...
  5. Không thể "unsend" — đã lộ.

💥 ROOT CAUSE: `UsersController.create()` trả `result.credentials.password`
   (cleartext từ input) trong HTTP response. Chỉ nên trả hash hoặc KHÔNG trả.

🔧 FIX (Option A — đơn giản nhất):
```typescript
// UsersController.ts:60-69 — XÓA `credentials` field
return NextResponse.json({
  user: {
    id: result.user.id,
    username: result.user.username,
    name: result.user.name,
    role: result.user.role
  }
  // BỎ: credentials: { ... }
}, { status: 201 })
```

🔧 FIX (Option B — UX-friendly hơn):
```typescript
// Chỉ trả password khi frontend explicit yêu cầu
const showOnce = req.nextUrl.searchParams.get('showCredentials') === 'true'
return NextResponse.json({
  user: { ... },
  ...(showOnce && { credentials: { ... } })
})
```

🔧 FIX (Option C — Best practice):
- Generate password server-side, gửi qua email/SMS cho user mới
- Frontend không bao giờ biết password
- Admin copy password từ secure channel để cấp cho user

⚠️ IMPACT:
- Production logs/gateways sẽ capture password cleartext
- Bất kỳ ai có quyền truy cập proxy logs hoặc admin browser có thể xem được
- Vi phạm OWASP Top 10: A02:2021 – Cryptographic Failures
- Đặc biệt nguy hiểm nếu admin dùng máy công cộng / shared workstation
